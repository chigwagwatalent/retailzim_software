# RetailZW POS Android release

Installable file: RetailZW-POS-v1.2.6-production.apk
Version: 1.2.6 (build 6)
Package: zw.co.retailzw.pos
Production server: https://admin.retailzw.co.zw
Requires: Android 7.0 (API 24) or newer
Architectures: ARM 32-bit, ARM 64-bit, x86_64
Signing: new RetailZW release key; APK v2 and v3 signatures verified

The APK passed archive integrity and 16 KB ZIP alignment checks. All 30 mobile tests passed. No physical-device installation was available for verification.

This new signing key supports fresh installations and future updates signed with the same key. Updating older RetailZW installations requires their original signing key. Do not uninstall an existing app with unsynced sales to work around a signing mismatch.

The original unsigned APK is retained for reference and cannot be installed directly.

Keep android/key.properties and android/app/retailzw-release.jks backed up securely. Both are excluded from Git.
