• Payment card numbers, CVV, or bank credentials

• Browsing history or web history
• SMS or call data
• Calendar or reminders

A4. Permissions Required

The RetailZW Android app requests the following system permissions:

• INTERNET — Required to sync sales data, authenticate users, and communicate with the RetailZW server.
• BLUETOOTH / BLUETOOTH_CONNECT / BLUETOOTH_SCAN — Required to discover and connect to Bluetooth thermal receipt printers. The app does not pair with or communicate with any device other than a receipt printer.
• BLUETOOTH_ADMIN — Required on older Android versions to manage Bluetooth connections to printers.
• ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION — Required by the Android operating system as a prerequisite for Bluetooth device scanning on Android 6–11. The app does not use, store, or transmit the user’s location. This permission is used solely to satisfy the Android OS requirement for Bluetooth scanning and will be removed when Android’s Bluetooth API no longer requires it.
• RECEIVE_BOOT_COMPLETED — Optional; used to restore the app’s shift state after device restart.

A5. Data Security Practices

• All data is transmitted over encrypted HTTPS/TLS connections.
• User passwords are never stored or transmitted in plain text; bcrypt hashing is used.
• Authentication uses short-lived JWT tokens.
• Offline/local data is stored in a private SQLite database inaccessible to other apps (Android’s app sandbox).
• No sensitive financial data (card numbers, bank details) is ever processed or stored.

A6. User Data Deletion

Users may request deletion of all their data by contacting privacy@retailzw.co.zw or by cancelling their account. Upon account cancellation, all server-side Customer Data is permanently deleted within 30 days. To delete locally stored offline data from a device, the user may clear the app’s storage via Android Settings > Apps > RetailZW > Storage > Clear Data, or by uninstalling the application.
